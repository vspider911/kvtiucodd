# kvtiucodd — сайт-витрина

Сайт студии kvtiucodd: продаёт разработку сайтов для кофеен, барбершопов и автосервисов.

- 3D-телефон на Three.js: при прокрутке переворачивается и показывает три примера, его можно крутить пальцем или мышкой.
- Каждый блок — полноэкранная сцена, привязанная к прокрутке (при прокрутке вверх идёт обратно).
- «Песочница» с физикой (Matter.js): детали сайта можно хватать и бросать, за стенки они не вылетают.
- Живые мини-демо: онлайн-запись, калькулятор, статус «Открыто / Закрыто» по Москве, рейтинг.
- **Форма заявки → Telegram-бот.** Заявка уходит на `/api/contact` и приходит вам в Telegram.

## Как открыть локально

```bash
python main.py
```

Затем откройте http://localhost:8000. Другой порт: `python main.py 8010`.

`main.py` отдаёт сайт и принимает заявки. Через обычный `python -m http.server` сайт откроется, но форма отправлять не будет.

## Настройка Telegram-бота

1. В Telegram напишите @BotFather → `/newbot` → получите **токен**.
2. Напишите своему боту любое сообщение, затем откройте
   `https://api.telegram.org/bot<ТОКЕН>/getUpdates` — число в `"chat":{"id": ...}` это **chat_id**.
3. Скопируйте `.env.example` в `.env` и впишите `TG_BOT_TOKEN` и `TG_CHAT_ID`.
   Файл `.env` не попадает в Git.

Без токена форма показывает посетителю ссылки на WhatsApp и Telegram.

## Защита от спама и лимит

- Не больше **2 заявок за сутки** с одного IP и с одного телефона/ника (сервер) + запоминание в браузере.
- Скрытое поле-ловушка и проверка времени: запрос без отметки времени молча отбрасывается, слишком быструю отправку (меньше 3 с) просим повторить.
- Контакт — только телефон или ник Telegram, не больше 2 ссылок в сообщении.
- Не больше 10 попыток за 10 минут с одного IP и 30 заявок в час всего; заявки с чужих сайтов отклоняются.

Настройки — в начале `api/contact.py`. Счётчики живут в памяти: локально — пока работает `main.py`,
на Vercel — пока жив экземпляр функции (для строгого лимита там нужна база, например Upstash Redis).

## Хостинг на Vercel

Add New → Project → репозиторий → Deploy. Затем Settings → Environment Variables:
`TG_BOT_TOKEN` и `TG_CHAT_ID` → Redeploy. Заявки обрабатывает `api/contact.py`.

GitHub Pages не подойдёт для формы: там нет сервера, заявки не отправятся.

## Что поменять перед запуском

- **Контакты в кнопках:** начало `script.js`, объект `CONFIG` (`whatsapp`, `telegram`).
- **Политика ПД:** `privacy.html` (оператор, сроки хранения).

## Файлы

| Файл | Что это |
|---|---|
| `index.html`, `style.css`, `script.js`, `scene.js` | сайт |

| `api/contact.py` | приём заявки и отправка в Telegram (Vercel и локально) |
| `main.py` | локальный сервер |
| `.env.example` | пример настроек бота |
